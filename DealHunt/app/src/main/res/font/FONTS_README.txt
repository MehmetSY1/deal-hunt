# Font Files Required

Download these font files and place them in:
app/src/main/res/font/

1. rajdhani_bold.ttf
   → Download: https://fonts.google.com/specimen/Rajdhani
   → Select: Bold (700)

2. rajdhani_semibold.ttf
   → Download: https://fonts.google.com/specimen/Rajdhani
   → Select: SemiBold (600)

3. dm_sans_regular.ttf
   → Download: https://fonts.google.com/specimen/DM+Sans
   → Select: Regular (400)

Or use Android Studio's "Download fonts" feature:
res/font → Right click → New → Font resource file → Search Google Fonts
